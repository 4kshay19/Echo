# Echo 🌐

> Real-time multilingual communication platform that allows two users speaking different languages to communicate naturally.

## 🚀 Project Vision

Echo is an SDE project designed to remove language barriers between users.

For example:

- User A speaks English.
- User B speaks Tamil.

Echo translates the conversation in real time so that both users can understand each other in their preferred languages.

## 🎯 Core Features

- 🌍 Multi-language communication
- 🎤 Speech-to-text
- 🔊 Text-to-speech
- 🔄 Real-time translation
- 👥 Two-user communication
- 🔐 User authentication
- 💬 Conversation management
- 📱 Modern responsive interface
